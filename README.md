 Build a complete Cybersecurity Threat Analytics and Risk Prediction Dashboard using the uploaded cybersecurity dataset.

First inspect and understand the dataset. Clean missing values, duplicates, inconsistent values and incorrect data types.

Perform exploratory data analysis and identify important cybersecurity KPIs, trends, attack patterns, major drivers, risks and opportunities.

Create an interactive dashboard using Python and Streamlit.

The dashboard should contain:

1. Executive Overview
- Total attacks
- Critical and high severity attacks
- Attack success rate
- Average risk score
- Attack trends
- Severity distribution

2. Threat and Attack Analysis
- Attack type distribution
- Malware, phishing, ransomware, DDoS and SQL injection analysis where available
- Monthly/weekly attack trends
- Most affected systems or devices
- High-impact attack categories

3. Risk Analysis
- High-risk systems
- Vulnerability analysis
- Risk factors
- Severity-based risk analysis
- Identify patterns associated with high-risk incidents

4. Actionable Insights
For every major finding, explain:
- Fact
- Insight
- Risk or opportunity
- Recommended business/security action

Create a clean and professional user interface.
